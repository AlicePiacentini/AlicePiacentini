[Dataset PR #34](https://github.com/ucam-eo/TEE/pull/34) · [Rasterization PR #33](https://github.com/ucam-eo/TEE/pull/33) · [Clustering PR #31](https://github.com/ucam-eo/TEE/pull/31)
